Custom Face Builder

Turns an image into the bg.bin + face.cfg pair the clock's Custom Face reads from an SD card — entirely in your browser, no install needed. Same output as tools/make_custom_face.py.

1. Choose an image

Best results near a 320:140 (~2.3:1) wide/short aspect ratio — this is the clock's digit strip only, not the whole screen, so it gets stretched to fit if the shape is very different.

2. Font & colours

#00FFFF
#FF4FA3

These two fonts are the only ones actually built into the firmware (also used by the big single-colour and rainbow grid faces) — a genuinely new third font needs a new glyph table compiled into the firmware itself.

3. Preview

Digit font is the real one; badge row layout is only a rough approximation of the real display.

4. Download

On the SD card, place both files at:

  1. /faces/custom/bg.bin
  2. /faces/custom/face.cfg

Insert the card, power on the clock, and LEFT/RIGHT-cycle the clock face to Custom (rainbow grid → retro LED → big cyan → gold → Custom). No card, or nothing at that path, and it just falls back to plain white digits on black.
