Digit Font Tracer

Upload a photo for each digit 0-9, trace it into a black & white silhouette, and download a ready-to-compile font header (Adafruit "GFX Free Font" format - the same format this firmware already uses for its badge text). Runs entirely in your browser.

Sets expectations, not just hype: a simple threshold works well on high-contrast photos - glowing digits on a solid black background, strong silhouettes. It struggles on gradients, reflections, and busy backgrounds (like a photorealistic metallic render) - those usually need the invert toggle and a careful threshold per digit, and may still come out rough. Check the specimen preview before downloading. This is also unverified on real hardware (no way to test-flash from here) - if positioning looks slightly off once you try it on the actual clock, that's a tuning pass, not a lost cause.

1. Settings

Target height ~100-130px reads well on the clock's digit cells. Width isn't fixed - each digit keeps its own natural proportions and gets cropped to just its own shape.

2. Upload & trace each digit

3. Specimen preview

All 10 traced glyphs side by side, at their real relative sizes. Re-check this after adjusting any threshold.

4. Download

Send the downloaded file's contents back so it can be wired into a new selectable digit font in the firmware (it needs a small amount of code on the firmware side to actually use it for a clock face - this tool only produces the font data itself).
